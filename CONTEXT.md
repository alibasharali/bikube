# Context

The domain language of Drovr. One entry per term: what it means here, and what it doesn't.

<!-- - **Term**: definition. Not to be confused with … -->

- **Startup command**: what Drovr types into a card's login shell, followed by Enter, right after each start: `Shell` (nothing), `Claude Code` (`claude` with the card's agent session id), or `Custom` (a one-line command run as written). Each card has its own; a workspace's default startup command is only the preset for new cards. Not to be confused with the login shell itself, which every start runs.
- **Agent session id**: a random UUID v4 a card gets at creation and keeps for life, whatever its startup command; Claude Code cards pass it to `claude --session-id` / `--resume` so reopening the card returns to the same conversation. Not the card's id, nor the PTY session id.
- **Stopped**: a card whose shell has exited; its screen and scrollback are gone, and opening it starts it again with its startup command. Replaces #4's "Exited (code N)". Not to be confused with `Couldn't start`, where the shell never ran.
- **Close**: stopping a running card's process from its menu or full-size view, after a confirmation; the card keeps its place, title, startup command and agent session id and becomes `Stopped`, so opening it again resumes it. Not to be confused with `Delete`, which removes the card, nor with `Back`, which leaves the process running.
- **Saved state**: the board as Drovr keeps it across restarts in `drovr-state.json`: every workspace, its columns and cards in order, their titles, directories, startup commands and agent session ids, and which workspace is active. Not terminal processes, screens or scrollback: after a restart every card is `Stopped` until it is opened. Not to be confused with UI preferences such as window size or the collapsed sidebar, which are not saved.
- **Board command**: `board`, the command every card's shell has on its PATH, through which a program in the card tells the board what it is doing: `board move <card> <column>` moves a card of the same workspace (`.` is the calling card) to the bottom of a column, `board status <card> <text>` sets its agent status. It reaches the running app over a socket only the same user can use, and works only from a card with a running shell. Not a global install: outside a Drovr card it isn't on the PATH.
- **Agent status**: a short text a program in a card sets with `board status`, shown in place of the card's last output line while the card is `Running` (`Running · <text>`); empty text clears it. It is cleared when the card's process stops or starts again, and never saved. Not to be confused with the card's status (`Running`, `Stopped`, `Couldn't start`), which Drovr derives itself.
